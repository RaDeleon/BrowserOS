# BrowserRAD 0.0.1-alpha.1

First experimental BrowserRAD release, based on BrowserOS Neo. This is the first “0.01 alpha”; the machine-readable version uses `0.0.1-alpha.1` and tag `v0.0.1-alpha.1`.

**Draft: the native executable is still building. No downloadable app has been validated yet.** This release must remain a draft until packaging, signature integrity and isolated launch/coexistence checks pass.

## What is included in the source

- BrowserRAD app identity, bundle ID, profile, state, MCP and extension identity, separate from Neo.
- Instant pointer path with existing native target checks; animated behavior remains configurable.
- Journal retention off the response path, with awaited append and protection against stale deletion.
- Shared bounded observations, optional navigation readback, bounded plans with fresh target resolution, and explicit postconditions.
- Opt-in same-origin retrieval and experimental WebMCP discovery/invocation.
- New README, contributor instructions, project diary, synthetic baseline and measurement protocol.

The deterministic helpers can be disabled using `BROWSERRAD_FAST_PATH=0`. No additional model provider is required.

## Planned download

- `BrowserRAD-0.0.1-alpha.1-macos-arm64.dmg` containing `BrowserRAD.app`.
- `SHA256SUMS` and `release-manifest.json` recording the actual artifact and build provenance.

This first alpha targets Apple Silicon macOS. Intel, Windows and Linux installers are not part of this release.

## Trust and installation status

The packaging target is **ad-hoc signed and not notarized**. No Developer ID signing identity was available during preparation. An ad-hoc signature checks integrity; it does not establish Apple-verified publisher identity or guarantee Gatekeeper acceptance. Platform passkeys and other managed Apple capabilities are not validated for this preview.

Installing the alpha is separate from publishing it. No installed Neo app, profile, credentials or connections are replaced by this release process. Automatic updates are disabled; future alphas require a separately downloaded build.

## Versions and evidence

The BrowserRAD release number is independent of inherited Chromium/BrowserOS engine versions. Packaging stamps the outer app's display version to `0.0.1`, its build to `1`, and its full release version to `0.0.1-alpha.1`; engine/framework versions remain unchanged. The manifest records both version families and exact source commits.

Prior source validation passed 1,726 Rust tests, 2,295 Bun tests and 1,326 Python build-system tests, with documented skips and warnings. These counts describe the implementation checkpoint, not a finished native-app acceptance test.

The Neo fixture baseline was 392 ms median across five warmed runs. A shared-capture prototype measured 11 ms versus 3 ms across ten paired runs inside Neo. These are narrow browser-execution observations, not an overall BrowserRAD speed claim. Client-reported token savings and total cost remain unmeasured.

## Before publishing this draft

- Complete native compilation and stage the separately branded app.
- Verify bundle identity, nested signatures, bundled resources and artifact contents.
- Launch with isolated test data while Neo remains running; verify no integration/profile interference.
- Verify the packaged download and its checksum.
- Update this note and manifest with actual validation results; attach the artifacts and publish as a prerelease.
