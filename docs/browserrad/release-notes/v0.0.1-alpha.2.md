# BrowserRAD 0.0.1-alpha.2

First experimental BrowserRAD release, based on BrowserOS Neo. This is the first “0.01 alpha”; the machine-readable version uses `0.0.1-alpha.2` and tag `v0.0.1-alpha.2`.

**Experimental Apple Silicon alpha.** The packaged app passed strict signature verification after ZIP extraction, an isolated headless JavaScript launch, and a native MCP shared-evidence/fill/save task with an independent readback. Stock Neo stayed running and the checked Claude/Codex configuration files were unchanged. Visible desktop onboarding and daily-use acceptance remain unverified.

## What is included in the source

- BrowserRAD app identity, bundle ID, profile, state, MCP and extension identity, separate from Neo.
- Instant pointer path with existing native target checks; animated behavior remains configurable.
- Journal retention off the response path, with awaited append and protection against stale deletion.
- Shared bounded observations, optional navigation readback, bounded plans with fresh target resolution, and explicit postconditions.
- Opt-in same-origin retrieval and experimental WebMCP discovery/invocation.
- New README, contributor instructions, project diary, synthetic baseline and measurement protocol.

The deterministic helpers can be disabled using `BROWSERRAD_FAST_PATH=0`. No additional model provider is required.

## Downloads

- `BrowserRAD-0.0.1-alpha.2-macos-arm64.zip` containing `BrowserRAD.app`; unzip it before launching.
- `SHA256SUMS` and `release-manifest.json` recording the actual artifact and build provenance.

This first alpha targets Apple Silicon macOS. Intel, Windows and Linux installers are not part of this release.

## Trust and installation status

This build is **ad-hoc signed, without hardened runtime, and not notarized**. The preview omits Developer-ID-only library validation so its ad-hoc frameworks can load; this is not the signing posture of a production notarized build. No Developer ID signing identity was available during preparation. An ad-hoc signature checks integrity; it does not establish Apple-verified publisher identity or guarantee Gatekeeper acceptance. Platform passkeys and other managed Apple capabilities are not validated for this preview.

Installing the alpha is separate from publishing it. No installed Neo app, profile, credentials or connections are replaced by this release process. Automatic updates are disabled; future alphas require a separately downloaded build.

## Versions and evidence

The BrowserRAD release number is independent of inherited Chromium/BrowserOS engine versions. Packaging stamps the outer app's display version to `0.0.1`, its build to `2`, and its full release version to `0.0.1-alpha.2`; engine/framework versions remain unchanged. The manifest records both version families and exact source commits.

Prior source validation passed 1,726 Rust tests, 2,295 Bun tests and 1,326 Python build-system tests, with documented skips and warnings. These counts describe the implementation checkpoint, not a finished native-app acceptance test.

The Neo fixture baseline was 392 ms median across five warmed runs. A shared-capture prototype measured 11 ms versus 3 ms across ten paired runs inside Neo. These are narrow browser-execution observations, not an overall BrowserRAD speed claim. Client-reported token savings and total cost remain unmeasured.

## Validation and limits

- Full native compile and initial package: approximately 4 hours 13 minutes with four compiler jobs.
- Alpha.2 signing/packaging checks: 40 signing tests and 7 guard tests passed; a native dynamic-library fixture passed.
- Actual ZIP extraction, nested code signatures, isolated headless launch and JavaScript execution passed.
- Actual packaged MCP server: shared observations and bounded fill/save passed; a separate MCP call independently confirmed the saved result.
- Existing Neo processes and checked client configuration files were preserved. The test-created BrowserRAD global skill guide was removed after testing.
- The app provisions its own BrowserRAD agent skill when launched. It is separate from Neo's guide.
- Visible desktop onboarding, platform passkeys, broad website coverage and matched speed/token/cost trials remain unverified.

Unzip the download to obtain `BrowserRAD.app`. No application was installed by this release process. This build is ad-hoc signed, without hardened runtime, and not notarized; it is an experimental preview rather than an Apple-verified production distribution.

## Packaging fixes since alpha.1

Native compilation completed in approximately 4 hours 13 minutes using four compiler jobs. Alpha.2 reuses that same executable code. It changes distribution signing and uses ZIP instead of the HFS DMG path. The alpha.1 source tag remains intact, and its failed packaging attempts remain recorded.
